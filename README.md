# Sitio Personal y Académico — Andrés Felipe Echavarría Peláez

Este repositorio contiene el código fuente de mi sitio web personal y académico, alojado en GitHub Pages bajo el dominio **`cachetown.fr`**.

---

## 🚀 Comandos Rápidos

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Descargar publicaciones más recientes (HAL + IdRef):**
   ```bash
   node scripts/fetch-publications.js
   ```

3. **Ejecutar servidor local de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
